# Southern Palms Beach Resort — 2026/2027 Tariff Landing Page

Upload `index.html` to the root of a GitHub repository (for example `spbr-rates`), then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

The page is responsive and uses the supplied tariff card as the source for rates and policies. The visual treatment follows the Southern Palms website, and the hero image is loaded from the resort's official website.
